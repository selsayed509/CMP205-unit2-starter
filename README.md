# CMP205 Unit 2 - Recipe Management System

This is your working repository for CMP205 Unit 2 (OO design, GUI, and database programming with Entity Framework). It contains a starter project you will use to develop your Recipe Management System.

**Using GitHub is optional and is not assessed.** If you choose to use GitHub, this repository provides a space for development and version control. You should commit your work regularly. Using version control is a useful professional practice and reflects good software development practice.

If you do not wish to use GitHub, you can download the project and work on it locally in Visual Studio without using GitHub.

At the end of the unit, you will submit your final Visual Studio project as instructed in the assessment brief.

## Getting started

1. Clone this repository (see the Student Handbook on MLS for step-by-step instructions).
2. Open `RecipeSystem/RecipeSystem.sln` locally in Visual Studio.
3. Build and run the app — you should see a blank window titled "Form1"
4. Configure your connection in `Data/AppDbContext.cs` to securely connect to your SQL database.
5. Work through the unit 2 requirements normally from within Visual Studio.
5. Commit and push regularly as you work.
